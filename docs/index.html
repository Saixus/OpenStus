Open Stus

What it is

Two panels, tabs, the works

Brief, medium, full, wide and detailed views, nine sort orders, tagging with Ins, Shift+arrows and the grey keys, quick search with Alt+letter, folder history, drive menus, and tabs (Ctrl+T) that remember themselves between sessions.

A command line that behaves like a terminal

Coloured as you type, prefix-filtered history on ↑/↓, a grey ghost suggestion accepted with →, Ctrl+R reverse search, Tab completion that narrows then lists, word-wise editing — and Ctrl+O reveals the real user screen with a transcript of every command run.

Viewer and editor with syntax colouring

C#, JavaScript/TypeScript, JSON, SQL, C/C++, Java, Python, PowerShell, XML/HTML, Markdown, CSV and the shell/config family, with multi-line constructs carried correctly across lines. Encodings and line endings survive the round trip byte for byte.

The classic look and keys

Blue panels, cyan frames, yellow column titles, a function key bar and the keyboard conventions every orthodox file manager has shared since Norton Commander — on Windows Terminal, conhost, or any terminal on Linux and macOS.

Zero dependencies

One assembly on top of the .NET base class library. Everything is drawn with plain VT escape sequences into an in-memory screen buffer, diffed and flushed once per frame, in 16 colours or 24-bit through a palette.

Built to be tested

The whole UI paints into a ScreenBuffer, so a frame can be rendered, asserted on and printed without a console. Over 1 750 tests cover rendering, input, panels, dialogs, the viewer, the editor, file operations and the shell.

Get it running

# needs the .NET 10 SDK
git clone https://github.com/Saixus/OpenStus.git
cd OpenStus
dotnet run --project src/OpenStus

# or publish a single-file stus executable
dotnet publish src/OpenStus/OpenStus.csproj -c Release -r win-x64

Alt+F7Find files by mask and content

About the name

The project is named after Vasyl Stus (1938-1985), the Ukrainian poet, translator and literary critic who became one of the leading voices of the Ukrainian dissident movement. The Soviet regime banned his work; he was arrested in 1972 and again in 1980, spent thirteen years in camps and exile for his convictions, and died in 1985 in Perm-36, the forced labour camp for political prisoners. He was reburied in Kyiv in 1989 and named a Hero of Ukraine in 2005. The name is a tribute and nothing more: the project has no connection with his family or estate.

Open Stus is released under the MIT License. It is an independent implementation - an open source alternative to Far Manager and Midnight Commander that shares no code with either; see NOTICE.md.
