# Notices

Dvopan is an independent, from-scratch implementation. It follows the conventions that every
orthodox file manager has shared since Norton Commander - two panels, a command line beneath them, a
function key bar, blue panels with cyan frames - and shares no code with any other file manager.

Norton Commander, Midnight Commander, Far Manager, Total Commander, Windows Terminal and PowerShell
are the names of their respective owners' products and are mentioned in this repository only to
describe conventions Dvopan follows or the alternatives it offers. Dvopan is not affiliated with,
endorsed by, or sponsored by any of them.
